## Architecture

**PURPOSE** &nbsp; Classify every LXC along three axes (Deep/Surface × Persistent/Consumable × Iterative/Static) → 8 archetypes.
**WHERE APPLIED** &nbsp; Every container in `registry/containers.yml`.

▲ **CONVENTIONS & GOTCHAS — the sigil decoded**
Archetype controls tunnel placement, backup policy, lifecycle expectations.

| Sigil | Code | Common name |

| ◆●▼ | DPS | Vault |
| ◆●▲ | DPI | Sanctum |

**PURPOSE** &nbsp; Post-Wave-3 layout — API layer unified on `CT 520`, staging DBs on `VM 510`.

## Infra & networking

### ☿ `protocol: http2` for Cloudflare Tunnel

**PURPOSE** &nbsp; Avoid intermittent 502s.
**WHERE APPLIED** &nbsp; Every `cloudflared` `config.yml`.

▲ **CONVENTIONS & GOTCHAS**
QUIC default thrashes; force HTTP/2.

⧈ **LINKS** &nbsp; `[[feedback_cloudflared_quic_instability]]`.

---

### ☿ Per-deep-container tunnels

**PURPOSE** &nbsp; Don't leak DPS/DPI containers into a shared-host tunnel with exceptions.
**WHERE APPLIED** &nbsp; Vaultwarden (`CT 570`), monitoring (`CT 595`), other deep containers.

▲ **CONVENTIONS & GOTCHAS**
Exceptions accumulate into systemic risk; give deep containers their own tunnel.

**LINKS** &nbsp; `[[feedback_deep_container_tunnels]]`, `[[reference_tunnel_topology]]`.

---

### ☿ `cloudflared` has no graceful reload

**PURPOSE** &nbsp; Plan for ~7s of outage on reload.
**WHERE APPLIED** &nbsp; Every `cloudflared` config change.

▲ **CONVENTIONS & GOTCHAS**
`systemctl reload cloudflared` *actually restarts*. Batch ingress changes.

**LINKS** &nbsp; `[[feedback_cloudflared_no_exec_reload]]`.

---

### ☿ Always pass tunnel UUIDs, never names

**PURPOSE** &nbsp; Avoid silent misrouting.
**WHERE APPLIED** &nbsp; `cloudflared tunnel route dns` and `tunnel info` invocations.

▲ **CONVENTIONS & GOTCHAS**
Name resolution can pick the wrong UUID. *Verify with `info` after every change.*

**LINKS** &nbsp; `[[feedback_cloudflared_name_resolution_bug]]`.

---

### ☿ Multi-zone certs on CT 520

**PURPOSE** &nbsp; Route hostnames in *`dubtown-server.us`* correctly.
**WHERE APPLIED** &nbsp; `cloudflared` invocations for `*.dubtown-server.us`.

▲ **CONVENTIONS & GOTCHAS**
Use `--origincert cert-dubtown.pem` — default `cert.pem` is the *`sacredjourney.io`* zone.

**LINKS** &nbsp; `[[reference_ct520_tunnel_certs]]`.

## MCP & service shape

### ☿ FastMCP behind tunnel: custom `main()`

**PURPOSE** &nbsp; Make FastMCP work with strict clients through Cloudflare Tunnel.
**WHERE APPLIED** &nbsp; Every FastMCP service exposed via tunnel.

▲ ✦ **CONVENTIONS & GOTCHAS — the canonical pattern**
`mcp.run()` is insufficient. Pattern: custom `main()` that runs uvicorn with `proxy_headers=True` and `forwarded_allow_ips="*"`, plus Starlette `CORSMiddleware` *before* the mounted MCP app.

⧈ **LINKS** &nbsp; `[[feedback_fastmcp_tunnel_setup]]`.

---

### ☿ Mounted vs standalone MCP paths

**PURPOSE** &nbsp; Know where to point clients.
**WHERE APPLIED** &nbsp; Every MCP server URL.

▲ **CONVENTIONS & GOTCHAS**
Mounted under FastAPI (Sacred Journey, Solar, Mars, Repository) → `/mcp/mcp`.
Standalone wrappers (Kairos, reporeason) → `/mcp`.
*Don't assume.*

**LINKS** &nbsp; `[[feedback_fastmcp_mounted_path]]`.

---

### ☿ ✦ MCP service auth (deployed) + por-mcp monorepo SoT

**PURPOSE** &nbsp; Lock down public MCP surfaces; one canonical home for standalone MCP server code.
**WHERE APPLIED** &nbsp; All first-party MCP endpoints (`kaimcp`, `scoring`, `solar-mcp`, `neo4j`, `grimoire`, `reporeason`, `agi-skills`, `mani-mcp`).

▲ ✦ **CONVENTIONS & GOTCHAS**
Auth: Authentik OIDC via fastmcp OIDCProxy, fleet-wired 2026-07-11; mutation tools additionally gate on `MCP_WRITE_TOKEN`. Raw REST APIs underneath remain public — any new public surface needs its own Authentik gate.
SoT: **por-mcp monorepo** (github.com/pwebster221/por-mcp, private; decided 2026-07-15) holds standalone MCP servers (agi-skills, kairos, solar, mani-mcp-proxy, reporeason). Each LXC clones the full repo, runs only its own server via `deploy.sh <name>`; `mcp-registry.json` is the fleet manifest. In-service MCPs (Sacred Journey, Mars, Grimoire, Repository-KG, VenusFace) stay with their parent app — registry-only. *Migration never changes a server's runtime* (systemd+venv default; compose only where already used).

**LINKS** &nbsp; `[[project_mcp_oauth_oidcproxy]]`, `[[project_paths_mcp_monorepo]]`.

## Workflow

### ♄ Build workflow (7-phase)

**PURPOSE** &nbsp; Proven pattern from PoR Hub consolidation.
**WHERE APPLIED** &nbsp; Any non-trivial feature.

▲ ✦ **CONVENTIONS & GOTCHAS — the seven phases**
*brainstorm → spec → plan → subagent execute → dev review → deploy → cleanup.*
Don't shortcut for features that touch more than one service.

⧈ **LINKS** &nbsp; `[[feedback_build_workflow]]`.

---

### ♄ Subagent-driven dev

**PURPOSE** &nbsp; Parallelize independent tasks; protect context.
**WHERE APPLIED** &nbsp; 12+ task implementation plans.

▲ ✦ **CONVENTIONS & GOTCHAS**
Fresh subagent per task; two-stage review (subagent + dev) catches real bugs. *Inline review acceptable for <30-line wiring tasks.*

**LINKS** &nbsp; `[[feedback_subagent_driven_dev_worked]]`.

---

### ♄ Macro decision → no micro re-asks

**PURPOSE** &nbsp; Don't waste turns on in-scope follow-ups.
**WHERE APPLIED** &nbsp; When a multi-step task has been authorized.

▲ **CONVENTIONS & GOTCHAS**
Permission is for the whole arc. *Re-ask only when the work leaves the authorized scope.*

**LINKS** &nbsp; `[[feedback_macro_no_micro_asks]]`.

---

### ♄ Optionality as a requirement

**PURPOSE** &nbsp; Redundant paths can BE the value.
**WHERE APPLIED** &nbsp; When user asks for both a custom tool AND an MCP.

▲ ✦ **CONVENTIONS & GOTCHAS**
Build both. *The redundancy is intentional.*

**LINKS** &nbsp; `[[feedback_optionality_as_requirement]]`.
