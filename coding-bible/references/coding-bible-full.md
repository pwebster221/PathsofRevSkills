## Inscription

This book is the seed document for the *Standards of Coding* directory of the Paths of Reverence ecosystem. It catalogs every framework, program, and rule currently load-bearing across the Proxmox host and its containers. Future per-topic docs in that directory will expand individual entries; this volume is the spine they hang from.

The structure is a triad:

> **☿ Frameworks** — what we build with.
> **☉ Programs** — what we have built.
> **♄ Coding Rules** — how we build.

The triad maps to three classical planets and three registers of attention. **Mercury** is the conduit — the libraries, protocols, and runtimes through which the work travels. **Sol** is illumination — the manifest services that the work has become. **Saturn** is the boundary — the rules of conduct, the discipline of doing.

A reader may begin anywhere. Most readers should begin with **How to read this Bible**, on the next page.

## How to read this Bible

⟞ *Deep register. Read once.*

The substantive content of this book is preserved verbatim from the `codingstandards.md` source-of-truth. What this volume adds is *register* — the visual and verbal frame that tells the reader what kind of fact they are looking at, where it sits in the system, and how to handle it.

**The Esoteric Diction tiers.** Three voices alternate through these pages.

- ⟜ **Tight** — operational. Verb-first, no hedges. Most **Conventions & Gotchas** lines, all error-state notes, and all path/port references.
- ⟝ **Standard** — explanatory. The working register, where most entry bodies live.
- ⟞ **Deep** — symbolic. Reserved for Part openings, this page, and the colophon.

The Bible is overwhelmingly Tight and Standard. Deep is the invitation, not the room.

**The callout family.** Six marks appear in the left margin of callouts:

- ▲ **Gotcha** — the load-bearing trapdoor. Read first if you are short on time.
- ◐ **Drift** — wrapper / client mismatch. Smoke-test before flipping toggles.
- ✦ **Pattern** — a worked pattern worth remembering.
- ✱ **Decision** — decided but not yet deployed.
- ⧈ **Memory** — a `[[memory-name]]` cross-reference into Paul's memory store.
- † **Read-only** — hands off. Production graphs, third-party hosts.

**The planetary marks.** Each Part opens with the glyph of the planet that rules it: ☿ Mercury for Frameworks, ☉ Sol for Programs, ♄ Saturn for Coding Rules. Inside a Part, planet glyphs may appear next to individual entries when a particular planet rules that entry — ♂ Mars for Mars Scoring, ☽ Luna for memory, ♃ Jupiter for frameworks of expansion. The presence of a mark means the relationship is load-bearing; the absence of a mark means none of the seven applies cleanly.

**The Three-Duality archetypes.** Every container in the fleet carries a three-axis classification rendered as a three-mark sigil:

| Axis | Left | Right |
|---|---|---|
| Depth | ◆ Deep | ◇ Surface |
| Permanence | ● Persistent | ○ Consumable |
| Velocity | ▲ Iterative | ▼ Static |

So **Vault** is ◆●▼, **Sanctum** is ◆●▲, **Laboratory** is ◆○▲, and so on. The sigil decodes itself once you know the axes; after a page or two the marks become mnemonic.

**Cross-references.** `[[memory-name]]` anchors point into Paul's memory store at `/root/.claude/projects/-root/memory/`. They are rendered in monospace and prefixed with ⧈ on first appearance per section. Paths, ports, and MCP tool names are monospace. Two neighbor documents are the authoritative ground when this book is silent:

- **SOT:** `/root/CLAUDE.md` — live infrastructure map (ports, IPs, hostnames).
- **SOT:** `/root/.claude/projects/-root/memory/MEMORY.md` — cross-session memory index.

**When this book disagrees with `CLAUDE.md`,** `CLAUDE.md` wins for live infrastructure facts. This book wins for conventions and rules.

## Web & API

### ☿ FastAPI

**PURPOSE** &nbsp; HTTP API framework for all production Python services.
**WHERE USED** &nbsp; Every API service on `CT 520` (Sacred Journey, Kairos, Mars, Solar, Mercury, Readings, KG Management, Alder facade, Lunamusic, Transit); the Alder runtime on `CT 540`.
**VERSION / SOURCE** &nbsp; `pip install fastapi` in per-service Python venvs under `/opt/<Service>/`.

▲ **CONVENTIONS & GOTCHAS**
Always paired with Pydantic v2. CORS via Starlette `CORSMiddleware` when fronted by Cloudflare Tunnel. systemd unit per service. Env vars in `/etc/systemd/system/<svc>.service.d/env.conf` drop-ins.

⧈ **LINKS** &nbsp; SOT: `/root/CLAUDE.md` (CT 520 port map).

### ☿ Pydantic

**PURPOSE** &nbsp; Data validation and serialization.
**WHERE USED** &nbsp; Every FastAPI service; every FastMCP request/response model.
**VERSION / SOURCE** &nbsp; Pydantic v2 across the fleet.

▲ ◐ **CONVENTIONS & GOTCHAS — wrapper drift**
When a service's Pydantic models change, downstream clients (MCP wrappers, DailyAPICall's `KairosClient`) silently return **422**. Smoke-test before flipping toggles.

⧈ **LINKS** &nbsp; `[[feedback_kairos_mcp_drift_risk]]`, `[[project_sacred_journey_wrapper_drift]]`.

### ☿ Starlette

**PURPOSE** &nbsp; ASGI plumbing under FastAPI (CORS, middleware, routing).

**LINKS** &nbsp; `[[feedback_fastmcp_tunnel_setup]]`.

## Networking

### ☿ Cloudflare Tunnel + cloudflared

**PURPOSE** &nbsp; External ingress for every public hostname.
**WHERE USED** &nbsp; Seven+ tunnels — per-deep-container plus shared-host. Hostnames in both *`dubtown-server.us`* and *`sacredjourney.io`* zones.
**VERSION / SOURCE** &nbsp; `cloudflared` installed per container or on host.

▲ **CONVENTIONS & GOTCHAS — four trapdoors**
1. **Force `protocol: http2` in `config.yml`** — QUIC default thrashes and causes intermittent 502s.
2. **`systemctl reload cloudflared` actually restarts** (~7s outage); batch ingress changes.
3. **`tunnel route dns <name>` and `tunnel info <name>` can resolve the wrong tunnel UUID** — always pass UUIDs, verify with `info`.
4. **Use `--origincert cert-dubtown.pem` for `dubtown-server.us` hostnames**; default `cert.pem` is the sacredjourney.io zone.

⧈ **LINKS** &nbsp; `[[feedback_cloudflared_quic_instability]]`, `[[feedback_cloudflared_no_exec_reload]]`, `[[feedback_cloudflared_name_resolution_bug]]`, `[[reference_ct520_tunnel_certs]]`, `[[reference_tunnel_topology]]`.
