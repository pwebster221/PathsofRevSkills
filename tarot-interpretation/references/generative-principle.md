# Generative Principle — Numbers 1–21 (Major module backbone)

Source: Linear project **Generative Principle** (PAT-212 → PAT-232), cross-checked
against `MajorArcana` nodes in the Repository. The Fool is **0** — the generative
precondition outside the count; the structure proper is **21 = 3 × 7**.

This is the Major module's structural layer. Each Major is read as *what its number
does* in the deck's self-generation, then colored by the card's Hermetic / astro /
Kabbalah correspondences.

## Classification

**9 emergent primes** (Enneagram-shaped) — irreducible generative acts:
`1, 2, 3, 5, 7, 11, 13, 17, 19`. Among them:
- **1** — Unity / Source, the precondition prime.
- **Pillar-base primes** `2, 3, 5, 7` — each founds a pillar (below).
- **Platform / completion primes** `11, 13, 17, 19` — completions standing *above*
  the composites (PAT-478).

**12 generative composites** (Zodiac-shaped) — trinity-operations:
`4, 6, 8, 9, 10, 12, 14, 15, 16, 18, 20, 21`.

## Reading a composite (the trinity-operation)

Smaller factor = **Operator**, larger = **Substance**, product = **Result**
(Operator · Substance → Result), mapped to **Cardinal · Fixed · Mutable**. A square
(4, 9, 16) is **self-action** — the number operating on itself.

## Generate / Produce rhythm

Parity alternation: **Odd → Even = Generate**, **Even → Odd = Produce**. The walk up
the sequence alternates the two moves; primes arrive only on a Produce step
(PAT-212–214).

## Septenary role (PAT-470)

- **Operator septenary** 1–7 = **Cardinal**
- **Substance septenary** 8–14 = **Fixed**
- **Result septenary** 15–21 = **Mutable**

The three septenaries are themselves one Operator·Substance·Result trinity at the
macro scale; The World (21) is the result of the result.
