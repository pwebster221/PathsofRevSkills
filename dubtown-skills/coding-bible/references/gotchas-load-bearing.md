# Load-Bearing Gotchas (distilled from the canon)

⟜ Every ▲ Convention & Gotcha line in the Coding Bible, pulled into one Tight-register
list. Read during triage or pre-deploy review. Mark legend: ▲ Gotcha, ◐ Drift, ✦ Pattern,
✱ Decision-pending, † Read-only / hands-off.

## Frameworks — Part I

### Web & API
- ▲ **FastAPI** — Always paired with Pydantic v2. CORS via Starlette `CORSMiddleware`
  when fronted by Cloudflare Tunnel. systemd unit per service. Env vars in
  `/etc/systemd/system/<svc>.service.d/env.conf` drop-ins.
- ▲ ◐ **Pydantic** — Wrapper drift: model changes silently return 422 in downstream
  clients. Smoke-test before flipping toggles.
- ▲ **Starlette** — For MCP servers behind Cloudflare Tunnel, add `CORSMiddleware`
  *explicitly*. FastMCP defaults don't suffice.
- ▲ **Uvicorn** — Behind a tunnel, run with `--proxy-headers` and
  `--forwarded-allow-ips="*"` so client IP is preserved.

### MCP
- ▲ **MCP** — Two server shapes: standalone wrappers (Kairos MCP, reporeason) → `/mcp`;
  mounted services (Sacred Journey, Solar, Mars, Repository) → `/mcp/mcp`. Don't assume.
- ▲ **FastMCP** — For tunnel deployment, `mcp.run()` breaks browser/strict clients.
  Pattern: custom `main()` running uvicorn with `proxy_headers=True` and
  `forwarded_allow_ips="*"`, plus Starlette `CORSMiddleware` mounted *before* the MCP
  app.

### Agent runtime
- ▲ **LangGraph** — Cost-sensitive. Minimize Opus, enforce token budgets, recover
  output from logs on failed runs rather than re-running. Output format matters
  downstream (PAT-427).
- ▲ **Langflow** — Blank `ChatInput.session_id` defaults to shared "New Session N"
  slots; Agent `n_messages` then pulls history from other flows (PAT-421). Always set
  an explicit `session_id`.
- ▲ **CrewAI** — Pin `setuptools<81` to keep `pkg_resources` available for telemetry
  imports. uv-managed venvs ship a setuptools that removed it.
- ▲ **Flowise / Dify / OpenHands** — For OpenHands in LXC, use the `ghcr.io` image
  (`docker.all-hands.dev` is **NXDOMAIN**); chown state and workspace bind mounts to
  uid 1000.
- ▲ † **Mani Protocol** — `CT 2001` is read-only and third-party. **Never edit,
  install, or restart there.** Dev goes on `CT 2002`. Outbound-restricted.

### Data
- ▲ **Neo4j** — Each application has a designated DB — pick the right port. Don't
  cross-write production from staging code. For symbolic correspondences, update via
  `mcp__claude_ai_repository__*`, not raw Cypher to production.
- ▲ **MongoDB** — Web UI is for inspection, not production querying.
- ▲ **ChromaDB** — Co-located with LangGraph in Alder's venv; not exposed beyond Alder.
- ▲ **PostgreSQL** — n8n-only. Not a general-purpose tier — the graph is primary.

### Infrastructure
- ▲ † **Ansible** — Vault password at `~/.ansible-vault-pass`. **Never commit or
  display.** Recurring deploy block: pip step hangs; workaround is to kill the playbook
  and do a manual `pct push` + restart.
- ▲ **Proxmox + LXC** — Unprivileged LXC with nesting + keyctl. This is the hypervisor
  host itself — system-level operations affect everything.
- ▲ **systemd** — Environment in `/etc/systemd/system/<svc>.service.d/env.conf`
  drop-ins. Always `daemon-reload` after edits.
- ▲ **Docker** — The exception, not the rule. Most services run native systemd/Python.
  Reach for Docker only when a vendor distribution requires it or native install is
  painful.

### Networking
- ▲ **Cloudflare Tunnel + cloudflared — four trapdoors:**
  1. Force `protocol: http2` in `config.yml`. QUIC default thrashes → intermittent 502s.
  2. `systemctl reload cloudflared` actually restarts (~7s outage). Batch ingress
     changes.
  3. `tunnel route dns <name>` and `tunnel info <name>` can resolve the wrong tunnel
     UUID — always pass UUIDs, verify with `info`.
  4. Use `--origincert cert-dubtown.pem` for `dubtown-server.us` hostnames; default
     `cert.pem` is the `sacredjourney.io` zone.
- ▲ **WireGuard** — Internal-only. Public traffic always exits via Cloudflare Tunnel.

### AI ops
- ▲ **LiteLLM** — Central routing point. Change model config here, not per-service.
- ▲ ✱ **Authentik** — Decided, partly deployed (PAT-509, 2026-05-16). Replaced
  single-user JWT for PoR Hub. Two follow-ups deferred — verify before assuming the
  pattern is fully complete for your service.
- ▲ † **Vaultwarden** — DPS (◆●▼ Vault) archetype. Gets its own tunnel, not shared.

### Compute
- ▲ ✦ **Swiss Ephemeris** — Reference docs are the two PDFs at workspace root. Kairos
  design principle is computational maximalism — compute the full chart at every
  meaningful moment, no shortcuts.

### Frontend
- ▲ **Astro** — PoR Hub consolidated into `CT 501` on 2026-04-12. Known auth UX gap:
  protected routes show empty pages when unauthenticated.
- ▲ **Gradio** — For internal LangGraph UIs only; not a substitute for the PoR site.

### Ops & monitoring
- ▲ **Grafana + Prometheus** — `CT 595`, DPI (◆●▲ Sanctum). Deep + persistent +
  iterative — its own tunnel.
- ▲ **Gitea + Gitea Mirror** — Mirror pulls from GitHub.
- ▲ **MinIO** — News pipeline PDF storage (PAT-425) lives here, not on `VM 510`.
- ▲ **n8n** — DB migrated off `CT 502` during consolidation.
- ▲ **MkDocs** — Generated from the container registry; rebuild after registry changes.

## Coding Rules — Part III

### Architecture
- ▲ **Three-Duality Container Archetype** — Classify every LXC along three axes (Deep
  ◆ / Surface ◇ × Persistent ● / Consumable ○ × Iterative ▲ / Static ▼). Eight
  archetypes: DPS Vault ◆●▼, DPI Sanctum ◆●▲, DCI Laboratory ◆○▲, DCS Bunker ◆○▼,
  SPI Forum ◇●▲, SPS Monument ◇●▼, SCI Workshop ◇○▲ (default), SCS Billboard ◇○▼.
  Archetype controls tunnel placement, backup policy, lifecycle expectations.
- ▲ **Service Consolidation Topology** — New API services go on `CT 520` unless an
  archetype reason demands isolation. New staging DBs go on `VM 510`, picking the next
  free port. Don't recreate per-service CT-based isolation that consolidation removed.

### Infra & networking
- ▲ **`protocol: http2` for Cloudflare Tunnel** — QUIC default thrashes; force HTTP/2.
- ▲ **Per-deep-container tunnels** — DPS/DPI containers get their own tunnel.
  Exceptions accumulate into systemic risk.
- ▲ **`cloudflared` has no graceful reload** — `systemctl reload` actually restarts
  (~7s outage). Batch ingress changes.
- ▲ **Always pass tunnel UUIDs, never names** — Name resolution can pick the wrong
  UUID. Verify with `info` after every change.
- ▲ **Multi-zone certs on CT 520** — Use `--origincert cert-dubtown.pem` for
  `*.dubtown-server.us`; default is the `sacredjourney.io` zone.

### MCP & service shape
- ▲ ✦ **FastMCP behind tunnel: custom `main()`** — `mcp.run()` is insufficient.
  Pattern: custom `main()` running uvicorn with `proxy_headers=True` and
  `forwarded_allow_ips="*"`, plus Starlette `CORSMiddleware` mounted *before* the MCP
  app.
- ▲ **Mounted vs standalone MCP paths** — Mounted (Sacred Journey, Solar, Mars,
  Repository) → `/mcp/mcp`. Standalone wrappers (Kairos, reporeason) → `/mcp`. Don't
  assume.
- ▲ ✱ **MCP service auth plan** — Decided 2026-04-22, rollout pending. `kaimcp`,
  `scoring`, `raw-charts`, `reporeason` publicly reachable until then.

### Data & client drift
- ▲ ◐ **KairosAPI client drift smoke-test** — Drift won't surface until the first real
  call. Smoke-test before flipping toggles.
- ▲ ◐ **Sacred Journey wrapper drift check** — Always check both the API and the MCP
  wrapper. Verify state via `/cycles/{id}/progress`.
- ▲ † **Which DB serves what** — Authoritative table is the `CT 520` service port map
  in `/root/CLAUDE.md`. **Production graph = `CT 500:7687`.**

### Auth
- ▲ ✱ **Authentik OIDC standard (PAT-509)** — Replaces single-user JWT. Paul's `sub`
  captured. Two PAT-509 follow-ups deferred — verify before assuming the pattern is
  complete for your service.

### Agent behavior
- ▲ ✦ **Honest unperformed errors** — No voice-rewrapping. If a subsystem failed, say
  so directly.
- ▲ ✱ **Esoteric Diction tiers** — Tight / Standard / Deep. Don't default to Deep.
- ▲ **Cost discipline (Alder)** — Minimize Opus. Enforce token budgets. Recover output
  from logs on failed runs rather than re-running.
- ▲ **Langflow `session_id` discipline** — Always set explicit `session_id`. Blank
  defaults bleed history across flows.
- ▲ † **CT 2001 is read-only / third-party** — Never edit, install, or restart. Dev
  goes on `CT 2002`.

### Workflow
- ▲ ✦ **Build workflow (7-phase)** — brainstorm → spec → plan → subagent execute →
  dev review → deploy → cleanup. Don't shortcut for features touching more than one
  service.
- ▲ ✦ **Subagent-driven dev** — Fresh subagent per task; two-stage review catches real
  bugs. Inline review acceptable for < 30-line wiring tasks.
- ▲ **Macro decision → no micro re-asks** — Permission is for the whole arc. Re-ask
  only when work leaves the authorized scope.
- ▲ ✦ **Optionality as a requirement** — When asked for both a custom tool AND an
  MCP, build both. The redundancy is the value.

### Documentation
- ▲ **Registry-driven infra docs** — Edit registry → re-run mkdocs playbook. Don't
  hand-edit generated docs.
- ▲ **MEMORY.md scope** — Save user profile, project state, feedback, references.
  Don't save anything derivable from `git log`, code, or `CLAUDE.md`. Each memory file
  has `name` / `description` / `type` frontmatter; index entries are one line.
- ▲ ✦ **Memory framing — records, not dictates** — Override when context warrants.
  Verify memory against live state before acting on it.
- ▲ **Linear renderer quirks** — Use fenced code blocks for dense tables / bullet
  lists. Linear silently drops content otherwise.
- ▲ **`tar --exclude-from` anchoring** — Bare `sessions/` won't match nested
  `.claude/sessions/`. Anchor patterns to the in-archive path or verify
  post-extraction.

## Pre-deploy review checklist

Before declaring a deploy ready, walk this list. Mark each ✓ or note the deferral.

- [ ] Tunnel: `protocol: http2` in `config.yml`?
- [ ] Tunnel: UUID, not name, in any new `tunnel route dns` / `tunnel info`?
- [ ] Tunnel: right `--origincert` for the zone?
- [ ] Container: archetype classified? Tunnel placement matches archetype?
- [ ] MCP: path is `/mcp` (standalone) vs `/mcp/mcp` (mounted) — clients pointed
  correctly?
- [ ] MCP: tunnel deployment uses custom `main()` with proxy headers + CORS?
- [ ] Auth: Authentik OIDC wired, or explicit deferral documented?
- [ ] Pydantic: smoke-tested against every non-git'd downstream client?
- [ ] Sacred Journey patch: API and wrapper both checked?
- [ ] Langflow flow: explicit `session_id` set on every ChatInput?
- [ ] Agent prompts: Tight/Standard tier, not Deep?
- [ ] `CT 2001`: untouched?
