# Esoteric Diction Tiers (mirror of brand-system.md §6)

## 6. Voice & Tone — the Esoteric Diction tiers

The source `[[project_esoteric_diction]]` already names three tiers. The brand system formalizes them and assigns each a *register glyph* so a reader can see which tier they are in at a glance.

### Tier I — **Tight** ⟜

Operational. Verb-first. No hedges, no metaphor, no warmup. The register of runbooks, MCP responses, and ops chatter.

> Force `protocol: http2`. QUIC default thrashes. Batch ingress changes — reload is a restart.

**When to use:** error messages, runbook steps, MCP tool outputs, terminal echo, any line where the reader is mid-task.

### Tier II — **Standard** ⟝

The working register. Plain English with one foot in the symbolic vocabulary. Most of the Coding Bible's prose lives here.

> The Cloudflare Tunnel will drop intermittently if it defaults to QUIC. Pin to HTTP/2 in `config.yml` and the 502s stop. Note that `systemctl reload cloudflared` is a restart, not a reload — batch ingress edits to amortize the ~7s outage.

**When to use:** documentation prose, entry bodies, explanatory passages, README files.

### Tier III — **Deep** ⟞

Symbolic synthesis. For teaching, onboarding, scaffolding *why*. Used sparingly — at section openings, in the "How to read this Bible" page, for the conceptual core of a pattern.

> The tunnel is a vein in the body of the host. QUIC, by its nature, treats the path as ephemeral — apt for the messenger but not for the work. We pin to HTTP/2 because the work asks for a path that holds across the reload, and the reload, here, is a small breaking of the world.

**When to use:** onboarding pages, the opening epigraph of each Part, conceptual essays, the colophon. *Never* default to Deep — Tight is the operational register and Standard is the working register; Deep is invitational.

### Register glyphs

Each entry, in the contributor-facing kit, may carry a tier glyph in its head — `⟜` Tight, `⟝` Standard, `⟞` Deep — set in Inter 9pt, Faded ink. The Coding Bible itself is mixed: entry bodies are Standard, Conventions & Gotchas are Tight, Part openings are Deep.
